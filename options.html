Komga Light Translator

一个多模态接口完成看图、识字、翻译和定位。扩展负责上下文、缓存与覆盖显示。

除此之外，扩展会持久保存滚动剧情摘要、人物、人名/术语和角色语气记忆。重新打开 Edge 后仍可继续使用。

通用 JSON 接口约定

请求 
{
  "model": "可选",
  "targetLanguage": "zh-CN",
  "image": {
    "mimeType": "image/jpeg",
    "dataBase64": "...",
    "width": 1600,
    "height": 2400
  },
  "page": {
    "bookId": "...",
    "pageNumber": 31
  },
  "context": {
    "rollingSummary": "...",
    "recentPages": [...],
    "translationMemory": {
      "characters": {},
      "terms": {},
      "speakerStyles": {}
    }
  }
}
返回 
{
  "blocks": [
    {
      "id": "b1",
      "source": "あいつは誰だ？",
      "translation": "那家伙是谁？",
      "x": 0.61,
      "y": 0.08,
      "width": 0.22,
      "height": 0.10
    }
  ],
  "pageSummary": "本页极短摘要",
  "contextUpdate": {
    "rollingSummary": "更新后的精简剧情摘要",
    "characters": {},
    "terms": {},
    "speakerStyles": {}
  }
}

x / y / width / height 使用 0~1 的归一化坐标。
