Komga Light Translator

一个多模态接口完成看图、识字、翻译和定位。扩展负责图片压缩、上下文、缓存与覆盖显示。

多模态模型

使用 llama.cpp + Qwen 多模态时建议开启。其他 OpenAI-compatible 服务如果不接受这些扩展参数，可以关闭。

上下文

除此之外，扩展会持久保存滚动剧情摘要、人物、人名/术语和角色语气记忆。重新打开 Edge 后仍可继续使用。

图片与阅读

大漫画推荐先用 1600~2000 px、0.85~0.90。边长越大、小字越清晰，但视觉推理更慢；JPEG 质量主要影响传输体积。

推荐起点：llama.cpp + 大漫画页

最大图片边长：1800
JPEG 质量：0.88
请求超时：180 秒
最大输出 Token：2048
上下文页数：3
llama.cpp / Qwen 优化：开启

通用 JSON 接口约定

请求 
{
  "model": "可选",
  "targetLanguage": "zh-CN",
  "image": {
    "mimeType": "image/jpeg",
    "dataBase64": "...",
    "width": 1200,
    "height": 1800
  },
  "page": {
    "bookId": "...",
    "pageNumber": 31
  },
  "context": {
    "rollingSummary": "...",
    "recentPages": [...],
    "translationMemory": {
      "characters": {},
      "terms": {},
      "speakerStyles": {}
    }
  }
}
返回 
{
  "blocks": [
    {
      "id": "b1",
      "source": "あいつは誰だ？",
      "translation": "那家伙是谁？",
      "x": 0.61,
      "y": 0.08,
      "width": 0.22,
      "height": 0.10
    }
  ],
  "pageSummary": "本页极短摘要",
  "contextUpdate": {
    "rollingSummary": "更新后的精简剧情摘要",
    "characters": {},
    "terms": {},

  }
}

x / y / width / height 使用 0~1 的归一化坐标。
